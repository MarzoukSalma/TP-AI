# TP-AI — Travaux Pratiques en Intelligence Artificielle

#### Description

Ce dépôt regroupe des travaux pratiques (TP) en Intelligence Artificielle et en Machine Learning, réalisés dans le cadre de ma formation en Génie Informatique.

#### Objectifs

* Comprendre les concepts fondamentaux du Machine Learning.
* Implémenter des algorithmes d'apprentissage automatique.
* Pratiquer l'analyse et la manipulation de données.
* Développer des compétences pratiques en IA avec Python.

####  Technologies utilisées

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

#### Contenu

Le dépôt contient différents travaux pratiques portant sur les algorithmes et les techniques d'Intelligence Artificielle.

####  Installation

Cloner le dépôt :

```bash
git clone https://github.com/MarzoukSalma/TP-AI.git
cd TP-AI
```

Créer un environnement virtuel :

```bash
python -m venv .venv
```

Activer l'environnement sous Windows :

```bash
.venv\Scripts\activate
```

Installer les dépendances :

```bash
pip install -r requirements.txt
```
